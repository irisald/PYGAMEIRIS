## Descripción del proyecto

Este repositorio reúne dos juegos hechos con Python y Pygame, con escenarios de colores pastel y controles fáciles de usar.

- **Pétalos de Luna:** se mueve una canasta de izquierda a derecha para atrapar 10 flores y esquivar las gotas de lluvia. La partida tiene tres vidas y un límite de tiempo.
- **Luna y la estrella:** se controla a una conejita llamada Luna para que llegue hasta una estrella en el jardín. Al tocarla, aparece un mensaje de felicitación.

## Objetivo general

Crear juegos interactivos con Python y Pygame para practicar el uso del teclado, el movimiento de personajes, la detección de colisiones y la actualización de lo que aparece en pantalla.

## ¿Qué es Pygame y para qué se utiliza?

Pygame es una biblioteca que permite crear videojuegos y otros programas multimedia con Python. Se utiliza para abrir ventanas, dibujar figuras, mostrar imágenes y texto, reproducir sonidos y responder a las acciones del jugador. En estos proyectos ayuda a crear los jardines, mover a Luna y la canasta, y detectar cuándo se atrapan flores o se alcanza la estrella.

## Relación con los temas vistos en clase

Pygame permite practicar varios conceptos de programación:

- **Ciclos:** el bucle principal repite el juego para revisar las acciones, actualizar los objetos y dibujar la pantalla.
- **Eventos:** el programa detecta cuando se presiona una tecla o se cierra la ventana.
- **Estructuras de datos:** se guardan datos del juego, como las vidas y el puntaje, y se organizan objetos como las flores y las gotas.
- **Funciones:** el código se puede separar en tareas, por ejemplo, mover al personaje, revisar colisiones o dibujar el escenario.
- **Condiciones:** permiten decidir qué pasa cuando se atrapa una flor, se pierde una vida o se llega a la meta.

Así, los juegos relacionan los temas de programación con resultados que se pueden ver y controlar en pantalla.

## ¿Qué significa que Pygame permite “tomar mucho o poco” de la librería?

Significa que se puede usar solo lo necesario para cada proyecto o combinar más herramientas cuando el juego lo requiere. Para una escena sencilla bastan la ventana, los eventos del teclado y el dibujo de figuras. Un juego más completo puede sumar imágenes, sonidos y otras funciones. No es necesario utilizar todas las herramientas de Pygame; se eligen las que ayudan a cumplir el objetivo del juego.

## Organización del trabajo por ramas

Durante el curso, cada parte del proyecto se trabajará en su propia rama para mantener los cambios organizados:

- **`main`:** contendrá la versión principal y revisada del proyecto.
- **`juego-petalos`:** se usará para trabajar en *Pétalos de Luna*.
- **`escena-luna`:** se usará para trabajar en *Luna y la estrella*.
- **`documentacion`:** se usará para actualizar el README y otros documentos del proyecto.

Cuando los cambios de una rama estén listos y revisados, se integrarán en `main`. Así se conserva una versión principal ordenada mientras se avanza en cada parte.

## Requisitos

- Python 3
- Pygame

Para instalar Pygame, abre una terminal y escribe:

```bash
pip install pygame
```

## Cómo jugar

- En **Pétalos de Luna**, usa las flechas izquierda y derecha para mover la canasta. Presiona Enter para comenzar, Espacio para pausar y R para reiniciar.
- En **Luna y la estrella**, usa las flechas o WASD para mover a Luna. Presiona R para empezar de nuevo y Esc para salir.
